# Security

Please don't report security problems in a public issue.

Use **[Report a vulnerability](https://github.com/majmichu1/local-quench/security/advisories/new)**
(the Security tab of this repository). Only the maintainer sees the report. Without a GitHub account,
e-mail contact@localquench.com with "Security" in the subject. Include what you found and the steps to
reproduce it. We aim to reply within a week.

Most interesting are: a model or a project file getting to run commands or reach files the user did
not allow, ways around the permission prompts, anything that exposes API keys, and the phone
connection or the data sharing server of localquench.com.
